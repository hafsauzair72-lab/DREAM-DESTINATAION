# Punjab Trails — Travel Website

A responsive travel landing page inspired by the supplied reference design, adapted for Punjab, Pakistan.

## Files
- index.html — page structure/content
- style.css — complete responsive styling
- script is included at the bottom of index.html for the mobile navigation

## How to run
1. Put all files in the same folder.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Replace the image URLs in `style.css` with your own Punjab photographs if desired.

## Main sections
- Hero / introduction
- Punjab journey route
- Destinations: Lahore, Multan, Bahawalpur, Rohtas
- Traveler Diaries
- Tour planning features
- Contact / social footer

The design uses Google Fonts and image URLs, so an internet connection is needed for the external fonts/images.
